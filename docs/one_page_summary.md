# One-page summary

LahoreSmog is an AQI prediction and alert system for Lahore. It fetches hourly air-quality and weather data from Open-Meteo, cleans the time series, builds lag and rolling features, and predicts PM2.5 at 1h, 6h, 12h, and 24h horizons. The modelling uses a strict time-based split and compares linear regression, random forest, and gradient boosting against a persistence baseline. Forecasts are served through FastAPI, streamed through a WebSocket, visualised in a Streamlit dashboard, and converted into deduplicated alerts when AQI crosses the sensitive-groups threshold. The project is designed to run locally on an 8 GB RAM laptop with no GPU, no paid APIs, and no cloud dependency. Its main limitation is that Open-Meteo air-quality values are modelled estimates rather than official station observations, so future work should connect Punjab EPA, PMD, or OpenAQ station exports.
